# 📝 ToDo List App

A simple and clean ToDo List application built with **React.js** and **Tailwind CSS**. This project is part of my *"Mastering MERN Stack by Building 30 Projects"* challenge.

## 🚀 Project 1 of 30 – Mastering MERN Stack

This project focuses on the frontend using React. It demonstrates basic concepts such as:

- React Functional Components
- useState Hook for State Management
- Dynamic Rendering of Tasks
- Tailwind CSS for Styling
- Icon usage with `react-icons`
